# Fonts

Self-hosted for the Deebo's College UI. All three families are open source.

- Source Serif 4, Adobe, SIL Open Font License 1.1. Downloaded from Google Fonts with the Impeccable font-fetch helper.
- Commit Mono, Eigil Nikolajsen, SIL Open Font License 1.1. Source: https://github.com/eigilnikolajsen/commit-mono
- Departure Mono, rektdeckard, SIL Open Font License 1.1. Source: https://github.com/rektdeckard/departure-mono

The Commit Mono and Departure Mono files are the same open-source files served by pi.dev. The Plantin MT Pro face from pi.dev is commercial and is not included. Source Serif 4 is the replacement display serif.
